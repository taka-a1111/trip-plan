名古屋 → 木曽駒高原（設営と川あそびの日）

クマ対策を徹底：木曽地域はツキノワグマ生息域で、6月には県の出没警報が出た（直近では7月上旬に新開地区で目撃）。食料・お菓子・クーラーボックス・生ゴミは就寝前に必ず車内へ。夜や朝夕の単独行動はせず、子どもだけでトイレへ行かせない。出発前に公式サイトの熊情報ページを確認。夜は15℃前後まで下がる予報なので長袖・防寒も忘れずに。
  • 移動自宅 → 中央道 中津川IC → 国道19号 → 木曽駒高原約2時間半
  • 1買物道の駅 日義木曽駒高原8:30–17:30木 営業
    キャンプ場入口交差点そばの道の駅。地元野菜と氷の買い足しに。大きなスーパーは木曽福島市街（車15分）、コンビニはファミリーマート木曽福島店が最寄り。
    地図
  • 2泊まる木曽駒冷水公園24時間1〜3泊目無料・予約不要
    標高約1,300mのフリーサイト。場内売店（冷水屋）・炊事場・シャワーあり、小川で水あそび・虫さがしができる。設営後はBBQと星空を。
    地図公式
  • 3温泉ペンション アルパイン（お風呂）9:00–21:00無休（〜9/30）
    キャンプ場すぐ上のペンションのお風呂。大人500円・18歳未満無料。シリカ水の給水もできる。
    地図

赤沢自然休養林（森林鉄道と森あそび）

ナビ注意：Googleマップが赤沢へ狭い林道を案内する事例があると公式が注意喚起中。必ず国道19号で上松市街まで行き、県道473号（赤沢線）経由で入ること。雨のあとは川の増水に注意し、清流あそびは現地で判断。
  • 移動キャンプ場 → 国道19号 → 上松市街 → 県道473号 → 赤沢約50分
  • 1観光赤沢森林鉄道9:30–15:30・30分毎金 営業
    樹齢300年の木曽ひのき林を走るトロッコ列車（往復25分）。夏休みダイヤで30分毎に運行。中学生以上1,000円・4歳〜小学生600円（夏休みイベント期間は+200円で木製パス）、駐車場700円。
    地図公式
  • 2遊ぶ赤沢自然休養林（森歩き・清流あそび）9:00–16:00金 営業
    遊歩道の森歩きと冷沢の清流あそび。入園は無料。園内の食堂は10:00〜14:30ごろまで営業しているので昼食もここで。
    地図公式
  • 3温泉せせらぎの四季10:00–21:00金 営業（水曜定休）
    帰り道の木曽福島郊外にある日帰り温泉。鉄分を含む赤褐色の湯。大人800円・小学生400円・未就学児無料で家族約2,000円。
    地図
  • 4泊まる木曽駒冷水公園2泊目
    キャンプ場へ戻って夕食と焚き火。
    地図公式

開田高原（木曽馬とそばとソフトクリーム）

引き馬は予約不可・当日受付のみ。乗馬時間帯（10:00〜11:50／14:00〜15:50）に合わせ、午前中に木曽馬の里へ着くのがおすすめ。土曜は観光客が増えるため早めの行動を。
  • 移動キャンプ場 → 国道361号 → 開田高原約40分
  • 1遊ぶ木曽馬の里 乗馬センター乗馬 10:00–11:50 / 14:00–15:50土 営業当日受付のみ
    日本在来種・木曽馬の牧場。引き馬ショート（約140m）は1人800円で4歳からOK、子ども2人で1,600円。屋内馬場があり雨でも乗れる。併設の食事センターで開田そばの昼食を。
    地図公式
  • 2グルメ開田高原アイスクリーム工房10:00–17:00土 営業（火曜定休）
    開田高原名物のソフトクリーム。定番のバニラのほか、とうもろこしソフトが人気。木曽馬の里から車5分。
    地図
  • 3泊まる木曽駒冷水公園3泊目
    午後はキャンプ場へ戻って小川で水あそび。夜はアルパインのお風呂と最終泊のBBQを。

木曽おもちゃ美術館 → 名古屋（帰路）

木曽おもちゃ美術館は8月は事前予約制。行くと決めたら前日までに公式サイトからWeb予約を。赤沢森林鉄道の切符提示で入館100円引きの案内あり（要確認）なので、金曜の切符は捨てずに持っていく。
  • 移動朝食・撤収 → 国道361号でおもちゃ美術館へ約25分
  • 1観光木曽おもちゃ美術館10:00–16:00（入館15:30まで）日 営業8月は要予約
    旧黒川小学校の木造校舎を使った木のおもちゃの体験ミュージアム。大人800円・こども600円で家族約2,800円。8月は事前予約制なので公式サイトから予約を。雨の日でも遊べる。
    地図公式
  • 移動美術館 → 国道19号 → 中津川IC → 名古屋約2時間半
有料費の目安：キャンプ0円＋赤沢森林鉄道・駐車場 約4,700円＋せせらぎの四季 約2,000円＋引き馬 1,600円＋アルパイン風呂 1,000円/回＋おもちゃ美術館 約2,800円 ＝ 合計 約12,000円＋食費・ガソリン代。
要確認：中止した北陸プランの予約（揖斐高原AFUREPPA・西俣キャンプ場・Alpen Outdoors しろとりフィールド）がキャンセル済みかを必ず確認。
最終判断：予約不要なので、8/19夜に天気（1時間ごとの雨・雷）と公式サイトの熊情報を見てから出発を確定する。
